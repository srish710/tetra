# Contributing to TETRA

1. Create an issue for a new feature or test.
2. Branch from main, for example feature/gripper or feature/motor-control.
3. Keep commits scoped and explain design tradeoffs.
4. For firmware, document hardware, wiring and test conditions.
5. For CAD, provide editable source, units, fastener dimensions and exports.
6. Never commit secrets or generated build directories.
7. Review mechanical/electrical safety before merging.
